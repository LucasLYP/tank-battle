# 🎮 坦克大战 (Tank Battle)

一个基于 HTML5 Canvas 的经典坦克大战游戏，完全使用原生 JavaScript 实现，无需任何外部依赖。

## 🕹️ 在线试玩

直接在浏览器中打开 `index.html` 即可开始游戏！

## ✨ 游戏特性

- **经典玩法**：还原经典坦克大战的核心体验
- **关卡系统**：随着关卡提升，敌人数量和难度会增加
- **多种地形**：包含砖墙、铁墙、水域和基地等多种地图元素
- **AI敌人**：敌方坦克拥有智能移动和射击行为
- **流畅操作**：支持键盘 WASD / 方向键移动，J / 空格射击
- **爆炸特效**：击中坦克或墙体时的粒子爆炸效果
- **暂停功能**：按 P 键随时暂停游戏

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `J` / `空格` | 发射炮弹 |
| `P` | 暂停 / 继续 |

## 🛠️ 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+)
- CSS3

## 🚀 本地运行

1. 克隆仓库
   ```bash
   git clone https://github.com/<your-username>/tank-battle.git
   ```
2. 进入项目目录
   ```bash
   cd tank-battle
   ```
3. 直接用浏览器打开 `index.html`，或启动一个本地服务器：
   ```bash
   npx serve .
   # 或
   python -m http.server 8000
   ```

## 📜 游戏规则

1. 控制绿色坦克，消灭所有红色敌方坦克
2. 保护底部的黄色基地（★），基地被摧毁则游戏结束
3. 砖墙可以被炮弹摧毁，铁墙无法摧毁
4. 消灭所有敌人后进入下一关，敌人会越来越多
5. 生命值为 0 时游戏结束
